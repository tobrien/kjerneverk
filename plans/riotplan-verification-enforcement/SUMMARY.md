# riotplan-verification-enforcement

## Overview

Add automated verification and enforcement system to prevent incomplete plans from being marked complete. Implement three strictness levels (advisory/interactive/strict) with configuration support, acceptance criteria validation, and automatic retrospective generation.

## Goals

Add automated verification and enforcement mechanisms to prevent incomplete plans from being marked as done. Implement acceptance criteria validation, automatic retrospective generation, artifact verification, and evidence-based reflections to ensure plan completion claims are accurate and verifiable.
