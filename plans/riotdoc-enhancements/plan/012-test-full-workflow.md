# Step 12: Test Full Workflow

## Goal
Validate the complete template-driven workflow with blog post and podcast script.

## Tasks

1. **Test blog post workflow**:
   - Create new blog post using explore_document
   - Verify template questions asked correctly
   - Select "Quick & Direct" approach
   - Generate draft (v0.1)
   - Revise draft (v0.2)
   - Finalize and publish (v1.0)
   - Verify all narrative captured
   - Verify checkpoints work

2. **Test podcast script workflow**:
   - Create new podcast script
   - Verify template questions asked correctly
   - Select "Structured Interview" approach
   - Generate script with segments/timing
   - Revise and finalize
   - Verify production notes captured

3. **Test outline manipulation**:
   - Create document with outline
   - Use tools to insert/move/delete sections
   - Verify outline changes reflected
   - Verify changes logged to timeline

4. **Test version numbering**:
   - Create multiple draft versions
   - Verify version increments correctly
   - Transition to v1.0
   - Create maintenance version (v1.1)

5. **Test narrative/checkpoint system**:
   - Verify narratives saved to both locations
   - Create checkpoints at key moments
   - Restore from checkpoint
   - Verify full conversation preserved

6. **Document issues and iterate**:
   - Note any problems or rough edges
   - Fix critical issues
   - Document known limitations
   - Create follow-up tasks if needed
