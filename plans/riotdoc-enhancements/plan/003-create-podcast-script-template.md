# Step 3: Create Podcast Script Template

## Goal
Convert the podcast script template prototype into the canonical template structure with lifecycle-aware questions and defined approaches.

## Tasks

1. **Convert existing podcast-script-template.md** to new structure:
   - Split questions into Idea/Draft Phase and Publishing Phase
   - Define approaches for different podcast formats
   - Include output document structure with timing/segments

2. **Define approaches**:
   - **Quick Episode**: Short format (10-15 min), minimal scripting, conversational
   - **Structured Interview**: Prepared questions, guest coordination, 30-45 min
   - **Narrative Series**: Multi-episode arc, detailed scripting, production notes

3. **Add podcast-specific elements**:
   - Segment structure (intro, main content, outro)
   - Timing considerations
   - Production notes (music, sound effects)
   - Show notes and timestamps

## Acceptance Criteria

- [ ] Podcast script template follows canonical structure
- [ ] Questions split by lifecycle phase
- [ ] Approaches defined for different podcast formats
- [ ] Template includes timing and production elements
- [ ] Works for solo, interview, and narrative formats

## Dependencies
- Step 1: Template structure defined
- Step 2: Blog post template (as reference)

## Estimated Effort
2-3 hours

## Notes
Podcast script is the second most-used template. Ensure it handles the complexity of audio production.
