# Blog Post Template

## Document Structure

```markdown
# {title}

{subtitle}

---

**Published**: {publish_date}  
**Author**: {author}  
**Tags**: {tags}  
**Categories**: {categories}

---

## Introduction

{introduction}

## {section_1_title}

{section_1_content}

## {section_2_title}

{section_2_content}

## {section_n_title}

{section_n_content}

## Conclusion

{conclusion}

---

**Call to Action**: {cta}

**Related Posts**: {related_posts}
```

## Template Variables

- `{title}` - Main title of the blog post
- `{subtitle}` - Optional subtitle/tagline
- `{publish_date}` - Publication date
- `{author}` - Author name
- `{tags}` - Comma-separated tags
- `{categories}` - Post categories
- `{introduction}` - Opening paragraph(s)
- `{section_*}` - Main content sections (variable number)
- `{conclusion}` - Closing thoughts
- `{cta}` - Call to action
- `{related_posts}` - Links to related content

## Structural Requirements

- Must have title
- Introduction is required
- At least 1 main content section
- Conclusion is optional but recommended
- Metadata (tags, categories) is optional
