# Step 01: Create Foundational Documents

## Goal

Establish the "bible" for all Kjerneverk messaging by creating comprehensive foundational documents.

## Context

These documents will serve as the single source of truth for all content generation about Kjerneverk. They must capture the philosophy, tone, audience, and core messaging that will be referenced by humans and AI assistants.

## Tasks

### 1. Create VISION.md
- Extract philosophical content from user narratives
- Emphasize "the thing is bigger than just the thing"
- Cover: constructs, process, lifecycle, metacognitive programming
- Include before/after comparisons for each construct (Prompt, Plan, Doc)
- Reference Beads (Steve Yegge's system) for RiotPlan context
- Explain tool independence as core motivator
- **Status**: ✅ Complete

### 2. Create CORE-MESSAGE.md
- Define the essence: "Structured formats for generative AI"
- Explain control and ownership over LLM outputs
- Create elevator pitch (30 seconds)
- Create one-liner description
- Create tweet-length version
- List key phrases to use and avoid
- Include audience-specific messaging
- **Status**: ✅ Complete

### 3. Create TONE-VOICE.md
- Define core tone attributes: pragmatic, opinionated, process-focused, intellectually honest
- Provide writing guidelines
- Include examples of good and bad tone
- Add audience-specific adjustments
- Establish the golden rule: "Write as if explaining to a smart colleague who's skeptical but open-minded"
- **Status**: ✅ Complete

### 4. Create TARGET-AUDIENCE.md
- Define primary audience: technical users working with generative AI
- Create detailed personas (4 personas)
- Explain communication preferences
- List what resonates and what doesn't
- Identify engagement channels
- Define success metrics
- **Status**: ✅ Complete

### 5. Create GLOSSARY.md
- Define all key terms: construct, ontology, metacognitive programming, tool independence
- Explain RiotPrompt concepts (cross-LLM translation, superposition of states, etc.)
- Explain RiotPlan concepts (lifecycle, standard process, multi-session workflow)
- Explain RiotDoc concepts (construction of meaning, narrative capture)
- Include anti-patterns (what we're moving away from)
- Provide usage examples
- **Status**: ✅ Complete

### 6. Create MAINTENANCE.md
- Explain how to use the foundational documents
- Define content hierarchy
- Provide update checklist
- Document consistency check process
- Include AI assistant instructions
- **Status**: ✅ Complete

## Acceptance Criteria

- [x] Tool independence emphasized throughout
- [x] Beads reference included for RiotPlan
- [x] Tone guidelines are clear and actionable
- [x] Audience personas are detailed and useful
- [x] Glossary covers all key concepts
