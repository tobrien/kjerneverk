# Step 12.5: Integrate Python Tests into Precommit Hook

## Objective

Add Python sampling tests to npm precommit script so they run automatically before commits and during release process.

## Context

**Why this step**: Ensures sampling tests run as part of standard development workflow. Catches regressions before they're committed.

**User requirement**: "When I run npm run pre-commit, is it also going to run the Python tests? I wanted to. And I also want that to run the Python tests when I go through GitHub Actions for release."

**Why now**: After CI/CD integration (Step 12), before documentation (Steps 13-14). Completes test automation.

- [ ] Add `test:sampling` script to package.json:
  ```json
  "test:sampling": "cd tests/sampling && python -m pytest test_sampling.py -v"
  ```
- [ ] Update `precommit` script to include Python tests:

  "precommit": "npm run build && npm run lint && npm run test && npm run test:sampling"

## Implementation Details

### Updated package.json Scripts

```json
{
  "scripts": {
    "precommit": "npm run build && npm run lint && npm run test && npm run test:sampling",
    "test:sampling": "bash scripts/run-sampling-tests.sh",
    "test:sampling:check": "bash scripts/check-python-env.sh"
  }
}
```

### scripts/check-python-env.sh

```bash
#!/bin/bash
set -e

echo "Checking Python environment for sampling tests..."

# Check Python version
if ! command -v python3 &> /dev/null; then
    echo "❌ Python 3 not found. Please install Python 3.11+"
    exit 1
fi

PYTHON_VERSION=$(python3 --version | cut -d' ' -f2)
echo "✓ Python $PYTHON_VERSION found"

# Check if in tests/sampling directory
if [ ! -f "tests/sampling/requirements.txt" ]; then
    echo "❌ tests/sampling/requirements.txt not found"
    exit 1
fi

# Check if FastMCP installed
cd tests/sampling
if ! python3 -c "import fastmcp" 2>/dev/null; then
    echo "⚠️  FastMCP not installed"
    echo "Run: cd tests/sampling && pip install -r requirements.txt"
    exit 1
fi

echo "✓ Python environment ready"
```

### scripts/run-sampling-tests.sh

```bash
#!/bin/bash
set -e

# Check environment first
bash scripts/check-python-env.sh

# Check for API keys
if [ -z "$OPENAI_API_KEY" ] && [ -z "$ANTHROPIC_API_KEY" ]; then
    echo "⚠️  No API keys found. Skipping sampling tests."
    echo "Set OPENAI_API_KEY or ANTHROPIC_API_KEY to run sampling tests."
    exit 0
fi

echo "Running Python sampling tests..."
cd tests/sampling
python3 -m pytest test_sampling.py -v --tb=short

echo "✓ Sampling tests passed"
```

### Integration with Release Workflow

Update `.github/workflows/release.yml` (or equivalent):

```yaml
- name: Setup Python
  uses: actions/setup-python@v5
  with:
    python-version: '3.11'

- name: Install Python dependencies
  run: |
    cd tests/sampling
    pip install -r requirements.txt

- name: Run sampling tests
  env:
    OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
    ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
  run: npm run test:sampling
```

## Python Sampling Tests

RiotPlan includes Python tests for MCP sampling functionality.

### Setup

1. Install Python 3.11+
2. Install dependencies:
   ```bash
   cd tests/sampling
   pip install -r requirements.txt
   ```
3. Set API key (choose one):
   ```bash
   export OPENAI_API_KEY="your-key"
   # OR
   export ANTHROPIC_API_KEY="your-key"
   ```

### Running Tests

```bash
# Run all tests (including Python)
npm run precommit

# Run only Python tests
npm run test:sampling

# Check Python environment
npm run test:sampling:check
```

### Skipping Python Tests

If you need to commit without running Python tests:
```bash
# Option 1: Commit without precommit hook
git commit --no-verify

# Option 2: Unset API keys temporarily
unset OPENAI_API_KEY ANTHROPIC_API_KEY
npm run precommit
```
```
